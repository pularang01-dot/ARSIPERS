# Audit Proyek

Saat pekerjaan dimulai, workspace hanya berisi `SUPER_PROMPT_MASTER_ARSIPERS_V2.md`; tidak ada repository ARSIPERS.
Karena itu tidak ada kode lama yang diaudit atau dipertahankan, dan aplikasi dibangun dari nol sesuai prompt.
Jika Anda memiliki repository ARSIPERS yang sudah ada, bagian yang dapat diambil: migrasi SQL, `src/lib`, dan komponen UI; lakukan audit
atas perbedaan skema sebelum menggabungkan.
